Description

Cette unité gère toute l'interface avec l'utilisateur : l'affichage des écrans dans le terminal et la lecture au clavier.
Les procédures sont regroupées par préfixe :
+ display : dessine un écran complet puis (généralement) attend la réponse de l'utilisateur
+ render : redessine uniquement une zone de l'écran de session, sans attendre
+ poll : lit le clavier sans attendre
Tous les écrans sont dessinés dans une fenêtre du terminal de 121 x 35, entourée d'un cadre. Le texte est blanc par défaut.

procedure displayLogin(var username: String);

Demande le nom d'utilisateur pour importer le profil

Le nom saisi est converti automatiquement en minuscules. Si l'utilisateur n'existe pas, un message d'erreur s'affiche et le nom est redemandé, jusqu'à ce qu'il existe ou qu'une entrée vide soit validée.

Paramètres
username
Le nom d'utilisateur d'un compte existant, ou une chaîne vide si l'utilisateur a annulé
procedure displayRegister(var firstname, username, description: String);

Demande les informations d'un nouveau compte

Il y a des conditions imposées sur les informations.
Si l'utilisateur ne les suit pas, des messages d'erreurs s'affichent et l'information est redemandée, jusqu'à ce que les entrées soient validées.
Le nom d'utilisateur est converti automatiquement en minuscules.

Paramètres
firstname
Le prénom saisi, peut être vide
username
Le nom d'utilisateur saisi. Si vide, l'inscription est annulée
description
La description saisie, peut être vide

Types

TStartChoice = (...);

Le choix de l'utilisateur dans le menu de démarrage.

Valeurs
  • IMPORT: Importer un profil existant.
  • REGISTER: Créer un nouveau profil.
  • QUIT_START: Quitter le programme.
  • NONE_START: Aucun choix.
TMainMenuChoice = (...);

Le choix de l'utilisateur dans le menu principal.

Valeurs
  • VIEW_PROFILE: Voir le profil et les statistiques.
  • VIEW_FOREST: Voir la forêt.
  • LOGOUT: Se déconnecter et revenir au menu de démarrage.
  • START: Démarrer une session de travail.
  • QUIT_MAINMENU: Quitter le programme.
  • NONE_MAINMENU: Aucun choix.
TTreeChoice = (...);

Le choix de l'utilisateur après avoir sélectionné une espèce d'arbre

Valeurs
  • CONFIRM_TREE: Utiliser cet arbre.
  • PREVIEW_TREE: Voir un aperçu de l'arbre entièrement poussé.
  • CANCEL_TREE: Revenir à la liste des espèces ou revenir à l'écran de session quand le temps de la pause est écoulé.
  • NONE_TREECHOICE: Aucun choix.
TSessionAction = (...);

Une action de l'utilisateur sur l'écran de session

Valeurs
  • TOGGLE_PAUSE: Mettre en pause ou reprendre le minuteur.
  • QUIT_SESSION: Quitter la session.
  • CHANGE_TREE: Changer d'arbre (uniquement pendant une pause).
  • SKIP_PHASE: Passer à la session suivante (uniquement pendant une pause).
  • NONE_SESSIONACTION: Aucune action.
TQuitAnswer = (...);

La réponse de l'utilisateur à la confirmation pour quitter la session.

Valeurs
  • QUIT_YES: Quitter. L'arbre en cours meurt.
  • QUIT_NO: Continuer la session.
  • QUIT_PENDING: Pas encore de réponse.
