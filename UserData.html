Description

Description

This unit stores and manipulates user information such as join date, identity and statistics and the forest of trees grown through completed sessions.

Aperçu

Classes, interfaces, enregistrements et objets

Nom Description
Enregistrement TDate A calender date (day/month/year) Used to check the user's join date.
Enregistrement TForest The user's forest: for each tree species, how many trees were grown and their name.
Enregistrement TUser the user profile with its forest and stats

procedure addTree(var user: TUser; tree: string);

Adds one grown tree of the given species to the user's forest. If the species is new, it is first added at the end of the list. If the species is new and the forest already holds MAX_SPECIES species, nothing happens.

Paramètres
user
The user to modify.
tree
Name of the species (case-sensitive).

Constantes

MAX_SPECIES = 100;

Maximum number of different tree species a forest can hold.
