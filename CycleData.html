Fonctions et procédures

function initialiseCycle(mode: TMode; focusDuration, shortBreakDuration, longBreakDuration, nbSessionsBeforeLongBreak: LongInt): TCycle;

Crée un nouveau cycle, prêt à être démarré. Le cycle commence à l'état NOT_STARTED, à la session 0 et à la phase FOCUS.

Retourne

le cycle initialisé.

function getMode(cycle: Tcycle): TMode;

This item has no description.

Retourne

le mode (CUSTOM ou POMODORO) du cycle.

function getCurrentSession(cycle: TCycle): LongInt;

This item has no description.

Retourne

Le numéro de la session de concentration en cours (0 si le cycle n'est pas démarré).

function getCurrentPhase(cycle: Tcycle): TPhaseSession;

This item has no description.

Retourne

La phase en cours (FOCUS, SHORT_BREAK ou LONG_BREAK).

function getCurrentPhaseDuration(cycle: Tcycle): LongInt;

This item has no description.

Retourne

La durée de la phase en cours, tirée du paramètre correspondant (concentration, pause courte ou pause longue).

function getState(cycle: Tcycle): TState;

This item has no description.

Retourne

L'état global du cycle (NOT_STARTED, IN_PROGRESS, FINISHED ou ABANDONED).

procedure startCycle(var cycle: TCycle);

Démarre le cycle : passe à la session 1, à la phase FOCUS et à l'état IN_PROGRESS. Ne fait rien si l'état n'est pas NOT_STARTED ou si focusDuration n'est pas strictement positif.

Paramètres
cycle
Le cycle à démarrer (modifié)
procedure nextPhase(var cycle: TCycle);

Passe à la phase suivante. Ne fait rien si l'état n'est pas IN_PROGRESS. Depuis FOCUS : passe à LONG_BREAK si nbSessionsBeforeLongBreak > 0 et que currentSession est un multiple de cette valeur, sinon à SHORT_BREAK. Depuis une pause : retourne à FOCUS et incrémente currentSession.

Paramètres
cycle
Le cycle à faire avancer (modifié).
procedure finishCycle(var cycle: TCycle);

Marque le cycle comme FINISHED. Ne fait rien si l'état n'est pas IN_PROGRESS.

Paramètres
cycle
Le cycle à terminer (modifié).
procedure abandonCycle(var cycle: TCycle);

Marque le cycle comme ABANDONED. Ne fait rien si l'état n'est pas IN_PROGRESS.

Paramètres
cycle
Le cycle à abandonner (modifié).

Types

TMode = (...);

Le type de cycle. CUSTOM : les durées sont choisies par l'utilisateur. POMODORO : le cycle Pomodoro classique. L'unité ne définit pas elle-même de valeurs par défaut, l'appelant doit les passer à initialiseCycle.

Valeurs
  • CUSTOM
  • POMODORO
  • NONE_MODE
TPhaseSession = (...);

La phase de la session dans laquelle se trouve actuellement l'utilisateur. (Avec LONG_BREAK toutes les N sessions de concentration)

Valeurs
  • FOCUS
  • SHORT_BREAK
  • LONG_BREAK
  • NONE_PHASESESSION
TState = (...);

L'état du cycle dans lequel se trouve actuellement l'utilisateur.

Valeurs
  • NOT_STARTED
  • IN_PROGRESS
  • FINISHED
  • ABANDONED
  • NONE_STATE
