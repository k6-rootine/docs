function initialiseCycle(mode: TMode; focusDuration, shortBreakDuration, longBreakDuration, nbSessionsBeforeLongBreak: LongInt): TCycle;

Creates a new cycle, ready to be started. The cycle starts in state NOT_STARTED, session 0 and phase FOCUS.

procedure startCycle(var cycle: TCycle);

Starts the cycle: goes to session 1 and state IN_PROGRESS.

Parameters
cycle
The cycle to start (modified)
procedure nextPhase(var cycle: TCycle);

Moves to the next phase. Does nothing unless the state is IN_PROGRESS. From FOCUS: goes to LONG_BREAK if nbSessionsBeforeLongBreak > 0 and currentSession is a multiple of it, otherwise to SHORT_BREAK. From a break: goes back to FOCUS and increments currentSession.

Parameters
cycle
The cycle to advance (modified).
procedure finishCycle(var cycle: TCycle);

Marks the cycle as FINISHED. Does nothing unless the state is IN_PROGRESS.

Parameters
cycle
The cycle to finish (modified).
procedure abandonCycle(var cycle: Tcycle);

Gives up the cycle: back to NOT_STARTED, session 0, phase FOCUS. Settings (mode and durations) are kept, so the cycle can be restarted.

Parameters
cycle
The cycle to reset (modified).

Types

TMode = (...);

The kind of cycle. CUSTOM : durations chosen by the user POMODORO : the classic Pomodoro cycle. The unit does not set default values itself, the caller must pass them to initialiseCycle.

  • POMODORO
