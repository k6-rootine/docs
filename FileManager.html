function userExists(username: string): Boolean;

Vérifie si un utilisateur existe

Elle cherche un fichier nommé username.dat dans le dossier PATH_USER.

Parameters
username
Le nom d'utilisateur à vérifier.
Returns

Un booléen indiquant si l'utilisateur existe.

procedure saveUser(user: TUser);

Enregistre un utilisateur dans un fichier. Créé/actualise username.dat et remplace l'ancienne sauvegarde. Le pseudo doit être un nom de fichier valide, sans chemin.

function loadUser(username: string): TUser;

(Charge un utilisateur depuis son fichier Le pseudo doit être un nom de fichier valide, sans chemin. Retourne un TUser vide si l'utilisateur n'existe pas.

Le nom d'utilisateur à charger.
Returns

function getAvailableSpecies(): TStringArray;

Récupère la liste des espèces d'arbres disponibles

Lis le fichier species.dat contenant la liste des espèces d'arbres disponibles et retourne un tableau de type TStringArray.

Returns

Un TStringArray contenant les noms des espèces d'arbres disponibles, au maximum MAX_SPECIES.
